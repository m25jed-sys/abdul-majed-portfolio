# Abdul Majed — Personal Portfolio

A responsive, single-page portfolio website built with HTML, CSS, and vanilla JavaScript.

## Included sections
- Home / introduction
- Personal details and education
- Technical skills
- Completed OJT experience at Securescope Systems Inc.
- Selected academic projects
- Email, phone, LinkedIn, and GitHub links

## Run locally
Open `index.html` in a browser. For local development, you can also use the VS Code Live Server extension.

## Publish with GitHub and Vercel
1. Create a new public GitHub repository (for example, `abdul-majed-portfolio`).
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. In Vercel, choose **Add New → Project**, import the GitHub repository, and deploy.
4. No build command is required. The site is static; use the repository root as the project root.
5. After deployment, open the public Vercel URL on a phone and test every link.
6. Generate the QR code only after the final Vercel URL is confirmed.

## Before printing the QR card
Confirm that you want your phone number and email publicly visible. Anyone who scans the QR code can access them.
